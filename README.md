# 发票汇编整理申报工具

这是一个本地运行的小工具，用来把发票 PDF 或图片汇编成一个 PDF，并在每一页页眉加入：

`报销金额： 原始凭证张数： 第 页/共 张`

## 使用方式

双击 `run_invoice_compiler.bat` 启动源码版；如果已经打包，也可以直接运行 `dist\InvoiceCompiler.exe`。

界面分为顶部汇总卡片、左侧操作区、中间页面列表和右侧实时预览区。

1. 点击“添加 PDF”添加 PDF 发票。
2. 点击“添加图片”时，先选择“新开一页”或“添加到选中页”，再选择一张或多张图片。
3. 如果选择“添加到选中页”，请先在列表中选中一个图片页。
4. 在“页眉共几张”里填写需要显示的总张数；也可以留空，页眉会显示“共 张”。
5. 双击列表行可修改报销金额；金额可以留空，留空时页眉只显示“报销金额：”。
6. 选中列表中的页面后，可点击“删除选中”或按 Delete 删除。
7. 选中页面后，可在右侧“排版预览”区域实时查看当前页面布局。
8. 点击“生成汇编 PDF”；默认文件名会自动带上当前日期和时间。

## 输出规则

- 所有输出页面统一为横向 A4。
- PDF 原页会缩小后放入页眉下方区域，避免与页眉重叠。
- 图片页支持一页放入多张图片，最多自动摆放 9 张；多图会优先保持横向一行排列。
- 图片页的原始凭证张数会按该页图片数量自动更新。
- 页眉布局为：报销金额靠左、原始凭证张数居中、页码/共几张靠右，并整体向页面中间收缩。
- 页眉中的“共几张”由用户填写；软件不会强制使用自动计算页数。
- 右侧预览区会显示选中页面的横向 A4 缩略排版，图片页会显示真实图片缩略图。

## 手动微调

如需自己调整页眉大小、内容边距、PDF 缩放、PDF 右移、图片间距或预览栏宽度，可修改 `invoice_compiler.py` 顶部的“页面版式微调区”变量。

## 识别说明

- 文字型 PDF：自动提取文字并识别金额。
- 扫描 PDF：会计入页数，但通常需要手动核对金额。
- 图片发票：如果本机安装了 `pytesseract` 和中文 OCR，会自动识别；否则可手动填写金额。

软件在本地处理文件，不上传发票。
